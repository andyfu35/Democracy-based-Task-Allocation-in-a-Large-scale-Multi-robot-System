# E9N — capacity-one, same-coordinate five-algorithm overview

**Status 2026-10-13:** newly implemented experiment candidate. Test on user Mac; **no E9N results exist yet**. Do not claim this is a new 10,000-execution rerun of every algorithm. No CI.

## Scientific purpose and registered cell

Compare five **separately named** task-allocation algorithms with N=T, **at most ONE task per robot**, in the same deterministic 100m×100m seeded robot/task coordinate scenes:

1. E9I original adaptive-plurality Voting — **immutable prior 100 Seeds/N evidence**.
2. E9J original CBAA — **immutable prior 100 Seeds/N evidence**, local/observer stop.
3. E9L Bertsekas-style distributed Price Auction epsilon=10 — **immutable prior 100 Seeds/N evidence**, price/home protocol, 160 guard and success censor.
4. E9N Voting Multi-task extension constrained to capacity1 — **new native execution** in the source-corrected E9M algorithm owner.
5. E9N genuine CBBA (Choi/Brunet/How 2009) constrained to capacity1 — **new native execution** in E9M CBBA owner. CBBA's multi-task Bundle advantage is intentionally disabled in capacity1.

**E9K Paid CBAA is user-authored termination engineering, NOT an original comparator, and is excluded.**

Fixed 20 N grid **N=5,10,...,100**; tasks=N; capacity=1; 100 paired scenario Seeds (0..99) per N; 30% independent per receiver losses on native method-specific packet types; Rady ROS delay residual + E9G hypothetical shared 144 Mbps Wi-Fi service, not measured physical Wi-Fi. Zero-loss three-seed and 30%-loss three-seed tests must pass before formal. New E9N methods execute **20×100×2=4000** new runs; historical E9I/J/L series each contain 20×100 archived executions, for a **five-series 10,000-method-case descriptive figure**, not 10,000 new executions. All methods use same N=T deterministic positional generator; an explicit validation function compares original E0 scenario with the new capacity1 scenario for every new execution. Network-draw seeding is method-specific, not forced shared random loss for all five.

For capacity1, best-insertion discounted reward 100×0.999^(robot→task distance) ranks each robot's own candidate tasks monotonically by Euclidean distance, but whole-team discounted sum is NOT an identical scalar objective to original Hungarian cost; do not present E9M discounted reward as historical Hungarian ratio. Report time, attempted sender Bytes, full completion (where original source permits), and E9N within-new-method route quality. E9I/J/L output uses frozen source-attested 20point CSV at `docs/figures/e9l_price/formal/three_algorithm_plot_source_20point.csv`; old per-seed raw ZIPs were NOT supplied as inputs and are NOT silently regenerated by this study.

**Critical limitations:** Voting full reliable Commit versus CBAA/CBBA/auction paid-or-unpaid local/observer stopping semantics differ. Original legacy E9I/J/L run source commits differ from E9N. Historical plot source has **no per-N E9I or E9J completion numerator**, so E9N chart intentionally leaves those points blank, not fabricated. Five-way *cross-method paired confidence intervals* are impossible from archived aggregate-only source; only E9N newly paired seeds are available. Failure/guard-censored observations remain in all-seed denominator. Do not publish a universal physical-radio speed ranking.
